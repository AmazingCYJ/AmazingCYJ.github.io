# Image Replacement Guide

You can replace these files with your own images later. Keep the same filenames to avoid changing config.

- `hero.svg`: homepage and page top banner. Recommended: `1920x1080` or `2560x1440`.
- `avatar.svg`: avatar/logo. Recommended: square image, `512x512`.
- `post-cover-1.svg`, `post-cover-2.svg`, `post-cover-3.svg`: default post covers. Recommended: horizontal images, `1200x680` or similar.

If you prefer PNG/WebP/JPG, update the paths in `_config.butterfly.yml` and each post front matter.
