# Image Replacement Guide

Put blog images under `source/assets/images/`, not under `public/`.

`public/` is generated by Hexo and can be recreated at any time. Files in `source/` are the real source files that Git tracks and deploys.

Current paths:

- `hero.png`: homepage, about, projects, archives, tags, and categories top banner.
- `avatar.png`: avatar/logo and favicon.
- `postcover/post-cover-1.png` to `postcover/post-cover-4.png`: default article cover pool.

Recommended sizes:

- Top banner: `1920x1080` or wider.
- Avatar: square image, `512x512` or larger.
- Article covers: horizontal image, around `1200x680` or `16:9`.
